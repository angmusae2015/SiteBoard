# 입력·기대 정답 예시

[input.json](input.json)은 현장 코드와 작업 텍스트, [output.json](output.json)은 기대 작업 내역입니다. 모델의 새 예측 결과가 아닙니다.

출력 항목은 workType·spec·quantity이며 의미는 [도메인 설명](../README.md#문제와-입출력)을 따릅니다.
실험 실행과 평가는 [루트 README](../README.md#google-colab-실행)와 [실험 색인](../experiments/README.md)을 기준으로 합니다. 기존 공통 단일 추론 CLI는 제거했습니다.
