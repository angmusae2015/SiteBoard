# 현장 원본 자료

이 디렉터리의 엑셀 원본과 사진을 보존합니다.

- 바로 아래 *.xlsm: 현장별 엑셀 원본.
- [photos/](photos/README.md): 시공 사진 원본.
- [tables/](tables/README.md): 보드판 표 크롭 이미지.

[엑셀 매핑](excel-mapping.md)과 [표 크롭·OCR](../../../tools/table_ocr/README.md)을 참고하세요.
원본 파일은 기본적으로 Git에서 제외되며 별도의 지속 저장소에서 함께 보존해야 합니다. 신규 자료 반영 전 사람의 검수가 필요합니다.
