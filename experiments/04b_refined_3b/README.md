## 재현 범위

정확한 당시 실행 코드가 확인되지 않아 과거 노트북 구성은 보류했습니다. 당시 분할·예측·정답·점수와 보유 모델을 보존하며 공통 최신 정제본으로 교체하지 않습니다.

data/work_type.json은 이관 시점 공통 마스터의 사본입니다. 생성 스크립트는 없으며 당시 실행과 동일 파일인지는 미검증입니다. 과거 JSON의 경로는 원문 기록이며 현재 실행용 경로로 사용하지 않습니다.

기존 config JSON은 이전 구조 정리에서 구성한 설정으로, 당시 실행값 전체를 복원한 것으로 검증되지 않았습니다.

어댑터 가중치와 토크나이저가 없어 보존된 모델을 이용한 재평가는 현재 불가능합니다.
