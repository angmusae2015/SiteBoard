# 09: 여러 학습 시드의 문장 결합 증강 효과 검증

학습 시드 43, 44, 45에서 문장 결합 증강 on/off를 쌍으로 비교합니다. [메인 스크립트](run_experiment.py)가 각 학습과 평가를 별도 Python 프로세스로 순차 실행합니다. 각 자식 프로세스가 완전히 종료된 뒤 다음 단계로 넘어가며, 메인은 GPU 라이브러리나 모델을 로딩하지 않습니다.

6개 조건의 학습과 평가를 모두 완료했습니다. 기존 채점의 3개 시드 평균은 증강 on 90.63%, off 89.85%이며 차이는 +0.78%p입니다. 같은 공종과 규격의 수량 합계가 같으면 항목 합산과 분리를 인정하는 추가 집계에서는 on 91.59%, off 90.39%, 차이 +1.20%p입니다. 원래 점수와 평가 JSON은 유지하며 전체 및 유형별 점수, 신뢰도, 오류 사례와 클러스터 44 분석은 [결과 분석](results/README.md)에 기록합니다.

기존 노트북과 이미 생성된 모델 및 평가 기록은 보존합니다. 시드 43의 on/off와 시드 44 on의 학습 및 평가는 기존 노트북 기록이며, 시드 44 off는 노트북 학습 후 Python 스크립트로 평가했습니다. 시드 45의 on/off는 학습과 평가 모두 아래 Python 스크립트로 실행했습니다. 새 스크립트는 노트북을 읽거나 실행하지 않습니다.

## 실행 방법

기존 Jupyter 커널을 종료한 뒤 프로젝트 루트의 터미널에서 실행합니다. 셀 실행만 중단한 커널이 잡고 있는 GPU 메모리는 새 메인 스크립트가 해제하지 않습니다. 프로젝트 가상환경과 루트 requirements.txt 및 pyproject.toml의 Unsloth 선택 의존성을 사용하며 패키지를 자동 갱신하지 않습니다.

```powershell
.\.venv\Scripts\python.exe experiments/09/run_experiment.py
```

보존된 설정의 기본 재개 순서는 다음과 같습니다. 현재는 6개 조건과 comparison.json이 모두 있어 완료 단계를 건너뛰고 기존 집계를 표시합니다.

1. seed_44_off 평가: 기존 완료 모델을 사용하며 재학습하지 않습니다.
2. seed_45_on 학습과 평가
3. seed_45_off 학습과 평가
4. 이전 평가 3개를 포함한 전체 6조건 집계

시작 위치는 experiment_common.py 상단의 EXECUTION_PARAMS에서 관리합니다. 시드와 on/off 목록, 학습과 평가 설정은 같은 파일의 딕셔너리에서 관리합니다. 전체 조건을 대상으로 실행하려면 다음 옵션을 사용합니다.

```powershell
.\.venv\Scripts\python.exe experiments/09/run_experiment.py --all
```

--all도 완료된 학습과 평가를 건너뛰며 강제 재학습하거나 기존 파일을 덮어쓰지 않습니다. 개별 단계를 직접 실행할 때는 같은 인터프리터로 train_desktop_unsloth.py 또는 evaluate_desktop.py에 --seed 44 --augmentation off와 같이 조건을 전달합니다. 경로는 프로젝트 루트 기준 상대 경로이며 스크립트가 작업 디렉터리를 루트로 맞춥니다.

메인은 sys.executable과 -u 옵션으로 자식을 실행하고 stdout과 stderr를 터미널에 직접 연결합니다. 단계 순서, 시작과 종료, 종료 코드 및 경과 시간과 함께 자식의 모델 로딩 메시지, Trainer 학습 스텝 및 에포크, tqdm 평가 처리 건수를 실시간으로 볼 수 있습니다.

첫 자식 실패 시 후속 실행을 중단합니다. Ctrl+C 시 자식이 종료되기를 기다리고, 종료하지 않으면 해당 자식만 종료한 뒤 기다립니다. 다른 프로세스나 기존 Jupyter 커널을 강제로 종료하지 않습니다.

## 완료 상태와 기존 기록

run_config.json의 training_completed 상태로 학습 완료를 판단하고 evaluation.json이 있으면 해당 평가를 건너뜁니다. 미완료 학습이 남아 있으면 자동 재개하거나 덮어쓰지 않습니다. 학습이 완료되고 평가만 없으면 저장 모델로 평가합니다. 기존 모델 또는 산출물이 있는 위치에 새 학습을 덮어쓰지 않습니다.

노트북 코드 해시와 새 Python 코드 해시의 일치 검사, 입력 및 모델 해시 대조, 환경 동일성 검사는 수행하지 않습니다. 원래 파일의 해시는 실행 출처 기록용으로만 남기며 이미 있는 기록은 수정하지 않습니다. 기존 노트북 형식의 평가와 새 스크립트 평가를 그대로 함께 집계합니다. 새 기록에는 해당 Python 구현의 해시, 프로세스 PID와 실행 파일 경로를 남깁니다. 같은 커널에서 실행하던 과거 결과와 비트 단위 예측 동일성을 보장하지 않습니다.

기존 comparison.json이 있으면 보존하고 그 내용을 표시합니다. 없으면 전체 6조건의 평가 보고서를 읽어 새로 저장합니다. 미완료 학습을 다시 수행하거나 새 조건을 보존하려면 기존 자료를 덮어쓰지 않는 새 실험 ID를 사용합니다.

## 비교와 해석

기존 채점의 시드별 on − off 차이는 43에서 −3건, 44에서 +15건, 45에서 +1건입니다. 미학습 복합 패턴의 평균 차이는 +4.50%p이지만 개선이 시드 44에 집중되어 있습니다. 이 시드는 on/off의 평가 배치와 구현도 달라 증강만의 효과로 귀속할 수 없습니다. 문장 결합이 복합 입력 해석에 도움이 될 가능성은 있으나 시드 전반의 일관된 향상을 확정하지 않습니다.

전체와 유형별 일치율, 값 토큰 최소 신뢰도, 시드별 on − off 차이와 양방향 정답 전환을 집계합니다. 시드 간 평균, 표본 표준편차, 범위와 우세 횟수, 클러스터별 차이 및 클러스터 22 제외 차이, 정답 작업 수별 차이를 함께 봅니다. Jupyter 표시 기능 대신 같은 내용을 터미널 표로 출력합니다.

같은 555건을 반복 평가하므로 555×3을 독립 학습 반복으로 취급하지 않습니다. 3개 시드는 효과 크기와 반복성을 보여주며 통계적 유의성을 자동 판정하지 않습니다. 토큰 노출량을 맞추지 않아 결합 자체와 추가 작업 및 토큰 노출의 효과는 분리하지 않습니다. test.jsonl을 학습 중 loss 평가에도 사용하는 기존 조건을 유지하며 최종 3에포크 모델로 생성 평가합니다. 평가 결과로 시드나 에포크를 골라 보고하지 않습니다.
