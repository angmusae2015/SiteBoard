# 09 학습과 평가 결과

학습 시드 43, 44, 45에서 문장 결합 증강 on/off를 비교한 6개 조건의 학습과 평가를 완료했습니다. 기존 엄격한 채점의 시드 평균은 on **90.63%**, off **89.85%**, 차이 **+0.78%p**입니다. 합산과 분리를 허용한 추가 기준은 on **91.59%**, off **90.39%**, 차이 **+1.20%p**입니다. 복합 입력 처리의 개선 신호가 있지만 시드 전반의 일관된 향상을 확정하지 않습니다.

[실험 목적과 실행 방법](../README.md), [고정 데이터](../data/README.md), [원본 실행 기록](../data/result/README.md)을 함께 확인합니다. 이 문서는 저장된 예측의 분석이며 재학습이나 재추론 결과가 아닙니다. 원래 데이터, 설정, 예측과 점수 및 가중치를 변경하지 않았습니다.

## 실제 실행과 완료 상태

Python 3.10.11, torch 2.11.0+cu128, transformers 4.57.6, peft 0.18.1, accelerate 1.15.0, bitsandbytes 0.50.2, 학습 Unsloth 2026.10.9가 기록되어 있습니다. 라이브러리와 GPU 및 dtype은 각 단계의 기록끼리 일치합니다.

on 학습 시간은 평균 70.76분, off는 67.00분입니다. 실행별 경과 시간의 관찰값이며 엄밀한 처리량 벤치마크는 아닙니다. 일부 실행에서 2에포크 이후 eval_loss가 증가하지만 중간 체크포인트의 생성 정확도는 평가하지 않았습니다. 최종 3에포크 모델을 동일하게 보고하며 결과에 따라 시드나 에포크를 고르지 않았습니다.

기존 정오 판정과 원문 예측의 엄격한 재계산이 모두 일치합니다. 학습 설정과 평가 보고서의 입력 및 어댑터 해시, comparison.json의 평가 파일 해시도 현재 보존 파일에 일치합니다. 검사는 일회성 명령으로 수행했으며 검증 전용 코드나 보고서는 추가하지 않았습니다. JSON 스키마 오류와 출력 512토큰 상한 도달은 여섯 실행 모두 0건입니다.

## 공통 오답과 정답 표현 검토

기존 기준에서 on은 세 시드 모두 정답 487건, 모두 오답 39건, 시드에 따라 정오가 바뀌는 사례 29건입니다. off는 각각 479건, 42건, 34건입니다. 여섯 모델이 모두 틀린 사례는 35건이며 seen_patterns 15건, unseen_complex_holdout 6건, unseen_rare 14건입니다.

- DG1 / image_id 54, source_index 85: 정답은 차열재마감 2000*600 수량 3.0을 한 항목으로 합산합니다. 44 off를 제외한 다섯 모델은 2.0과 1.0으로 분리해 총수량은 같으나 기존 채점에서는 오답입니다. 44 off는 무보온덕트벽체를 누락해 추가 기준에서도 오답입니다.
- DG2 / image_id 96, source_index 303: 정답은 무보온덕트벽체와 차열재마감 600*200을 각각 수량 1.0 두 항목으로 보존하지만 세 on 모델과 45 off는 2.0 한 항목으로 합칩니다. 43 off와 44 off는 금속관 수량도 달라 합산 허용만으로 회복되지 않습니다.
- DG2 / image_id 200, source_index 406: 원문은 2100*100, 정답은 2100*1000입니다. 다섯 모델은 원문 규격을 따르며 44 off는 정답 규격을 출력하지만 무보온덕트를 보온덕트로 예측합니다. 원본 사진과 현장 근거를 확인해야 하며 정답 오류로 확정하지 않습니다.

이 사례들은 항목 합산과 개별 보존의 기준, 단면과 양면 및 마감 횟수의 적용 범위, 텍스트와 정답의 대응을 구분해 검토할 필요를 보여줍니다. 정답이나 점수를 임의로 고치지 않았습니다.

## 클러스터 44

[cluster.json](../data/cluster.json)의 대표 패턴은 `입상 보 <DIM>*<CNT> 차열마감<NUM>번`입니다. 치수와 개수, 차열마감 횟수가 함께 등장하며 `천장 무`, `임상 보`, `보덕트 ... 단면`, `보덕트 ... 양면` 변형도 포함합니다. 총 8건으로 학습 7건, seen_patterns 평가 1건이며 입상과 벽체 공종이 함께 있습니다.
