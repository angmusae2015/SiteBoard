# 09 모델 저장

seed_43_on, seed_43_off, seed_44_on, seed_44_off, seed_45_on, seed_45_off에 실행별 어댑터와 공식 토크나이저를 저장합니다. 각 조건은 같은 기본 모델 revision에서 새로 학습하며 다른 조건의 가중치나 체크포인트를 이어 사용하지 않습니다.

각 디렉터리의 checkpoints/에는 에포크별 체크포인트를 최대 2개 유지합니다. 자동 생성 체크포인트 내부에 관리 README를 추가하지 않습니다. 원래 입력은 [데이터](../README.md), 설정과 평가 기록은 [실행 결과](../result/README.md)에서 관리합니다.

가중치, 토크나이저와 체크포인트는 Git에서 제외합니다. 이 안내와 각 실행 README, 최종 adapter_config.json은 추적합니다. 모델 저장 완료 후 파일 해시를 기록합니다. 현재 실행 스크립트는 재실행 전에 해시를 대조하지 않으며 완료 상태를 기준으로 건너뜁니다. 분석 시 일회성 해시 대조에서는 평가 기록과 현재 어댑터가 일치했습니다. 기존 자료를 덮어쓰거나 자동 삭제하지 않습니다.
