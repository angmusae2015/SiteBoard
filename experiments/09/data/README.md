# 09 데이터와 고정 분할

공통 정제본 [dataset.json](../../../dataset/processed/dataset.json)에서 09의 준비 스크립트로 독립 생성합니다. 마스터는 08의 이관 시점 마스터를 바이트 변경 없이 복사한 파일이며 생성 코드는 추가하지 않습니다.

| 파일 | 내용 |
| --- | --- |
| work_type.json | 현장별 공종과 규격 규칙 |
| cluster.json | 2,123건의 231개 패턴 클러스터와 원천 해시 |
| split_meta.json | 학습 1,568건, 평가 555건의 인덱스와 평가 유형 |
| train.jsonl | 모든 실행에서 공유하는 원본 학습 메시지 |
| test.jsonl | 모든 실행에서 공유하는 고정 평가 메시지와 식별자 |

분할 시드는 42이며 학습 시드 43, 44, 45와 구분합니다. 유사도 임계값 0.85, 일반 클러스터 평가 비율 0.18, 홀드아웃 ID [20, 22, 35, 36, 42, 65]를 유지합니다. 평가 유형은 seen_patterns 392건, unseen_complex_holdout 74건, unseen_rare 89건입니다.

준비 시 07 및 08과 마스터, 클러스터, 분할과 모든 메시지 및 메타데이터를 전수 대조합니다. 공종과 규격, (site, image_id) 중복, 학습과 평가 교집합 및 원천 인덱스 누락도 일회성 명령으로 검사합니다. JSON과 JSONL은 UTF-8, ensure_ascii=False를 사용하며 JSONL 줄바꿈은 LF입니다. 실행 시 다른 실험의 코드나 생성 데이터를 읽지 않습니다.

[모델 저장](models/README.md)과 [결과 저장](result/README.md)은 조건별로 구분하며 입력 파일은 복제하지 않습니다. 데이터 준비 스크립트는 이미 있는 파일을 덮어쓰지 않습니다.

## 완료 후 데이터 검증

6개 평가 기록의 (site, image_id, source_index), 입력과 정답을 이 디렉터리의 test.jsonl에 전수 대응했습니다. test_type은 test.jsonl과 split_meta.json의 유형별 원천 인덱스에 일치합니다. 학습 1,568건과 평가 555건은 공통 정제본 2,123건을 중복과 누락 없이 분할하며, 원문과 정답 및 공종과 고정 규격은 공통 정제본과 이 실험의 마스터에 일치합니다. 학습 설정의 입력 해시와 평가 기록의 입력 및 어댑터 해시도 현재 보존 파일과 일치합니다. 검사는 일회성 명령으로 수행했고 검증 파일은 추가하지 않았습니다.

## 클러스터 44

대표 패턴은 `입상 보 <DIM>*<CNT> 차열마감<NUM>번`으로, 덕트 치수와 개수에 차열마감 횟수가 뒤따르는 형태입니다. `천장 무`, `임상 보`, `보덕트 ... 단면`, `보덕트 ... 양면` 표현도 포함합니다. 총 8건이며 학습 7건, seen_patterns 평가 1건입니다. 대표 이름이 입상이어도 소속 사례 전체가 입상 공종인 것은 아닙니다.

평가 사례는 DG3 / image_id 9, source_index 442의 `9번 천장 무 1800*800*2 차열마감2번`입니다. 기록된 정답은 무보온덕트입상 1.0과 무보온입상차열재마감 1.0이며, 여섯 모델 모두 마감 수량을 2.0으로 예측했습니다. 합산과 분리를 허용해도 총수량이 달라 오답입니다. 학습 사례와 현장별 산정 기준을 함께 검토할 내용은 [결과 분석](../results/README.md#클러스터-44)에 기록하며 원문과 정답은 보존합니다.
