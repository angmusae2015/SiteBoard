# 09 실행 기록과 비교 집계

시드와 조건별 접두사 seed_<시드>_<on/off>로 JSON을 구분합니다. 6개 조건의 학습과 평가 및 comparison.json 집계가 모두 완료되어 학습 설정 6개, 학습 이력 6개, 평가 6개와 비교 집계 1개를 보존합니다. 결과 해석, 합산 및 분리 허용 추가 집계와 클러스터 44는 [결과 분석](../../results/README.md)에 기록합니다. Python 실행 경로는 학습과 평가를 각각 별도 프로세스에서 실행하며 기존 저장 경로를 유지합니다.

| 파일 이름 | 내용 |
| --- | --- |
| seed_43_on.run_config.json 등 | 실제 설정, 입력과 구현 해시, 환경, 학습 상태, 시간, 최종 스텝, 모델과 이력 해시 |
| seed_43_on.training_history.json 등 | Trainer 학습 이력, 에포크별 eval_loss와 실행 통계 |
| seed_43_on.evaluation.json 등 | 전체 및 유형별 점수, 원문 예측과 정답, 식별자와 유형, 스키마와 출력 상한, 값 토큰 신뢰도, 파일 해시와 실행 환경 |
| comparison.json | 6조건 요약, 시드별 쌍 비교, 클러스터 및 작업 수별 비교와 시드 간 변동 |

새 Python 실행 기록은 process에 PID와 스크립트 경로를 추가합니다. experiment.implementation_sha256은 해당 스크립트와 공통 모듈의 해시이며, 기존 노트북 실행 기록의 값과 같다고 요구하지 않습니다. 과거 JSON의 값이나 경로 문자열은 수정하지 않습니다. 기록된 해시는 출처 보존용이며 실행 전 해시 대조나 환경 동일성 검사는 하지 않습니다.

메인은 학습 설정의 training_completed 상태를 확인하고, 해당 평가 JSON이 이미 있으면 평가를 건너뜁니다. 보존된 기본 재개 설정은 seed_44_off 평가부터 시작해 seed_45_on 및 seed_45_off 학습과 평가로 이어지지만 현재는 모두 완료되어 건너뜁니다. 미완료 학습은 자동 재개하거나 덮어쓰지 않고 중단합니다. 자식 실패 시 후속 단계도 중단합니다.

실제 평가 배치는 seed_43_on, seed_43_off, seed_44_on이 1이고 seed_44_off, seed_45_on, seed_45_off는 4입니다. 앞의 세 평가는 기존 노트북 기록, 뒤의 세 평가는 Python 스크립트 기록입니다. 시드 44 쌍은 평가 배치와 구현이 달라 증강만의 차이로 해석하지 않습니다. 원본 기록의 경로 문자열과 구현 해시를 그대로 보존합니다.

strict_schema_multiset_v1 채점은 정확한 필드와 값 타입을 검사하고 작업 순서는 무시하되 중복 개수는 유지합니다. 채점 및 신뢰도 계산은 기존 평가 구현을 유지합니다. 집계는 배열 위치 대신 (site, image_id, source_index)로 케이스를 대응하고 기록된 정오 판정을 사용합니다. 원본 정답이나 당시 채점은 바꾸지 않으며 별도의 평가 기록 재검증 코드는 두지 않습니다.

값 토큰 최소 신뢰도는 JSON 문법을 제외한 workType, spec, quantity 값 구간의 케이스별 value_min_confidence입니다. 그룹 최소값은 정답과 오답을 모두 포함한 케이스 최솟값의 min이며 평균과 구분합니다. 미확인 건수와 null을 보존하고 0으로 대체하지 않습니다.

전체 6조건의 평가를 읽어 시드별 on − off 차이와 양방향 정답 전환, 3개 시드의 평균, 표본 표준편차, 범위와 우세 횟수를 집계합니다. 전체와 유형별 비교 외에 클러스터별 비교, 클러스터 22 제외 비교와 정답 작업 수 1개 또는 2개 이상 비교를 포함합니다. 학습 시드 42의 과거 결과는 합치지 않습니다.

집계 파일이 없으면 새로 저장하고 기존 comparison.json이 있으면 덮어쓰지 않고 그 내용을 터미널에 표시합니다. 3개 시드의 평균 차이가 양수라는 이유로 통계적 유의성을 선언하지 않습니다.

기존 엄격한 채점의 평균은 on 90.63%, off 89.85%입니다. 동일 공종과 규격별 수량 합계로 비교하는 추가 기준의 평균은 on 91.59%, off 90.39%입니다. 추가 기준은 원문 예측을 일회성 명령으로 재집계한 진단이며, evaluation.json과 comparison.json의 채점이나 신뢰도 및 코드 동작을 바꾸지 않습니다. 추가 평가 JSON이나 검증 전용 코드는 생성하지 않았습니다.
