# 08 실행 기록

08 학습과 평가를 완료했으며 다음 원본 JSON을 보존합니다. 07의 실행 결과를 복사하거나 08의 결과로 사용하지 않습니다. 전체 및 유형별 점수, 신뢰도, 07 대비 개선과 퇴행 및 합산과 분리 허용 추가 기준은 [결과 분석](../../results/README.md)에 기록합니다.

| 파일 | 기록 항목 |
| --- | --- |
| `run_config.json` | 실제 파라미터, 증강 확률 0.0, 입력 해시, 환경과 라이브러리 버전, 모델 revision, dtype, GPU 메모리, 실행 상태와 소요 시간 |
| `training_history.json` | Trainer 학습 loss와 에포크별 eval_loss, 스텝과 실행 통계 |
| `evaluation.json` | 엄격한 채점 기준, 전체 및 유형별 통계, 예측과 정답 원문, 식별자와 유형, 값 토큰 신뢰도, 스키마 적합성과 출력 상한 여부, 파일 해시와 실행 환경 |

학습과 평가는 기존 결과가 있으면 중단합니다. Unsloth 학습은 중단 또는 오류 시 상태와 수집한 학습 이력을 기록하며, 같은 경로에 재실행하여 과거 기록을 덮어쓰지 않습니다.

비교 기준은 07의 동일한 555건 평가입니다. 전체 및 유형별 일치율과 개선 및 퇴행 건수를 함께 확인하고 중복 행 개수를 포함한 정답을 그대로 유지합니다. 신뢰도는 케이스별 workType, spec, quantity 값 토큰의 최소 확률이며 유형별 최솟값에는 정답과 오답을 모두 포함합니다. 미확인 값을 0으로 채우지 않습니다.

07과 같은 test.jsonl을 학습 중 loss 평가에도 사용합니다. 같은 시드와 학습 스케줄을 유지하며 증강 제거로 줄어든 토큰 노출을 추가 에포크로 보상하지 않습니다. 실제 비교는 환경과 설정 및 데이터 대응을 확인한 뒤 [실험 설계](../../README.md#결과-비교-방법)에 따라 수행합니다.

run_config.json의 상태는 training_completed이며 최종 이력은 시드 42, 3에포크, 588스텝입니다. 학습은 RTX 4070, BF16, Unsloth이며 생성 평가는 배치 1, greedy, 최대 새 토큰 512입니다. 기존 엄격한 채점은 488/555, 87.93%, 저장 예측의 합산 및 분리 허용 추가 집계는 494/555, 89.01%입니다. 입력과 식별자, 정답과 유형 및 기록의 파일 해시를 일회성 명령으로 대조했습니다. 기존 정오 판정은 그대로 유지하고 추가 집계 JSON이나 검증 전용 파일은 생성하지 않았습니다.
