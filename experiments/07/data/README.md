# 07 데이터와 분할

공통 정제본에서 이 실험의 `cluster.py`, `partition.py`, `build_dataset.py`를 순서대로 실행해 생성한 독립 입력입니다.

| 파일 | 내용 |
| --- | --- |
| [work_type.json](work_type.json) | 06에 보존된 이관 시점 공통 마스터의 내용 변경 없는 사본. 생성 코드 없음 |
| [cluster.json](cluster.json) | 2,123건의 231개 패턴 클러스터와 원천 파일 해시 |
| [split_meta.json](split_meta.json) | 학습 1,568건, 평가 555건. 시드, 비율, 홀드아웃 ID와 인덱스 |
| [train.jsonl](train.jsonl) | 간결한 지시문, 전체 현장 규칙, 원본 텍스트와 학습 정답 |
| [test.jsonl](test.jsonl) | 고정 평가 메시지, 원본 식별자와 평가 유형 |

06과 같은 분할 인덱스를 사용합니다. 평가 유형은 `seen_patterns` 392건, `unseen_complex_holdout` 74건, `unseen_rare` 89건입니다. 원본 텍스트, 정답과 메타데이터는 유지하며 지시문과 현장 규칙 JSON의 공백만 줄였습니다. JSON과 JSONL은 UTF-8로 저장하고 한글을 이스케이프하지 않습니다.

공종 및 규격은 준비 과정에서 이 디렉터리의 마스터와 일회성 명령으로 전수 대조했습니다. `(site, image_id)` 중복, 학습과 평가의 교집합 및 누락, 평가 유형별 인덱스와 합계도 확인했습니다. 생성 코드와 노트북에서 이 검사를 반복하지 않습니다. 랜덤 결합은 학습 중에만 수행합니다.

학습과 평가를 완료했으며 [models/](models/README.md)에 어댑터와 토크나이저, 체크포인트를, [result/](result/README.md)에 원본 실행 설정과 학습 및 평가 JSON을 보존합니다. 평가 해석은 [결과 분석](../results/README.md)을 따릅니다. 기존 산출물은 덮어쓰지 않습니다. 자세한 설정과 실행 순서는 [실험 안내](../README.md)를 따릅니다.

## 결과 분석 시 확인

학습 1,568건과 평가 555건의 공종 및 고정 규격, 규격 없음의 빈 문자열을 이 실험의 마스터와 전수 대조했습니다. 식별자 중복, 학습과 평가의 교집합, 전체 2,123개 원천 인덱스의 누락이 없습니다. 평가 기록의 식별자, source_index, 원문 입력, 정답과 유형이 현재 test.jsonl과 일치하며 기록된 입력 해시도 일치합니다.

마스터 적합성은 입력 의미의 정확성을 보장하지 않습니다. 입력의 규격과 정답의 차이, 보온 구분 및 오픈구 누락 의심 사례는 결과 분석에 남겼으며 데이터와 과거 점수는 수정하지 않았습니다.
