# 07 평가 결과와 확인된 내용

Qwen3-8B의 비추론 랜덤 결합 QLoRA 실행은 완전 일치율 **90.45% (502/555)**를 기록했습니다. 목적과 조건은 [실험 안내](../README.md), 원본 JSON과 실제 환경은 [실행 기록](../data/result/README.md)을 따릅니다. 분석을 위해 모델을 재학습하거나 재추론하지 않았으며 저장된 예측과 점수를 보존했습니다.

## 평가 요약

| 유형 | 평가 건수 | 정답 수 | 오답 수 | 일치율 | 값 토큰 최소 신뢰도 (0~1) |
| --- | ---: | ---: | ---: | ---: | ---: |
| 전체 | 555 | 502 | 53 | 90.45% | 0.348599 |
| seen_patterns | 392 | 369 | 23 | 94.13% | 0.348599 |
| unseen_complex_holdout | 74 | 64 | 10 | 86.49% | 0.355267 |
| unseen_rare | 89 | 69 | 20 | 77.53% | 0.455315 |

값 토큰 최소 신뢰도는 JSON 문법 토큰을 제외하고 workType, spec, quantity 값 구간과 겹치는 생성 토큰으로 계산한 케이스별 value_min_confidence를 사용합니다. 표의 각 행은 해당 유형의 정답과 오답을 모두 포함한 케이스 최솟값의 min이며 평균이 아닙니다. 표에는 소수 여섯째 자리까지 반올림했고 원본은 [evaluation.json](../data/result/evaluation.json)에 보존합니다. 신뢰도 미확인은 0건이며 없는 값을 0으로 채우지 않았습니다.

평가 기록의 (site, image_id), source_index, 원문 입력과 정답을 같은 실험의 test.jsonl과 전수 대응하고, test_type을 테스트 메타데이터 및 split_meta.json의 유형별 인덱스와 확인했습니다. 유형별 건수와 정답 수의 합계는 전체와 일치합니다. 현재 테스트 정답과 기록된 정답에 차이가 없으며, 학습과 평가 식별자 중복 및 인덱스 누락이 없습니다. 공종과 고정 규격은 07의 work_type.json과 전수 대조했습니다.

채점은 strict_schema_multiset_v1입니다. 정확한 세 필드와 값 타입을 검사하고 문자열 양끝 공백, 수량 소수점 넷째 자리 반올림을 정규화합니다. 작업 순서는 무시하지만 같은 객체의 중복 개수는 유지합니다. 저장된 일치 여부가 이 기준으로 재계산한 값과 모두 일치했습니다. JSON 스키마 오류와 출력 512토큰 상한 도달은 모두 0건입니다.

## 성능과 오류 양상

| 정답 작업 수 | 평가 건수 | 정답 수 | 일치율 |
| --- | ---: | ---: | ---: |
| 1개 | 213 | 204 | 95.77% |
| 2개 이상 | 342 | 298 | 87.13% |

희소 유형은 평가의 16.0%이지만 오답의 37.7%를 차지합니다. 다중 작업과 희소 패턴이 취약하며 JSON 형식보다 의미 해석과 수량 계산에 개선 여지가 있습니다. 홀드아웃은 지정 클러스터의 격리이며 모든 입력이 다중 작업이거나 현장 전체가 미학습이라는 뜻은 아닙니다.

오답은 다음 순서로 서로 겹치지 않게 분류했습니다. 같은 공종과 규격별 총수량이 일치하면 합산 및 분리 차이, 그 외에 공종과 규격의 다중집합이 같으면 수량만 다른 오류, 나머지는 기타 오류입니다. 원래 채점은 바꾸지 않습니다.

| 양상 | 건수 | 관찰 |
| --- | ---: | --- |
| 합산 및 분리 방식만 다름 | 7 | 동일 공종과 규격별 총수량은 같지만 객체 수와 배분이 다름 |
| 수량만 다름 | 18 | 단면과 양면 환산, 반복 개수 및 마감 횟수의 적용 |
| 기타 | 28 | 공종과 규격 선택, 작업 추가 및 누락, 복합 오류 |

- DG1 / image_id 1: 차열재마감 정답 5.5를 3.0과 2.5로 분리했습니다. 총수량 계산 오류와 객체 표현 차이를 구분해야 합니다.
- SB / image_id 617: 실리콘마감 무D 80*17 양면의 수량 17을 1로 출력했습니다.
- SB / image_id 636: 덕트 *2와 마감 2번에서 덕트 2 및 마감 4를 각각 1과 2로 출력했습니다.
- DG3 / image_id 12, 14, 28: 앞의 임상을 첫 작업에는 입상으로 해석하지만 뒤의 작업은 벽체로 출력했습니다. 위치 정보의 적용 범위 유지가 취약한 양상입니다.
- JW / image_id 25, 62: PVC 규격 30을 해당 현장의 허용 목록에 없는 32로 출력했습니다. JSON 스키마가 유효해도 마스터 제약을 위반할 수 있습니다.

## 신뢰도와 검토 대상 선별

전체 value_avg_confidence는 0.996461이며 정답 평균은 0.997274, 오답 평균도 0.988766입니다. 이 값은 케이스별 값 토큰 평균의 평균으로 최소 신뢰도와 다릅니다. 모델이 높은 확률로 오답을 출력할 수 있으므로 정답 확률로 해석하지 않습니다.

| value_min_confidence 기준 | 검토 대상 | 포착한 오답 | 검토 제외 건수 | 제외 건에 남는 오답 |
| --- | ---: | ---: | ---: | ---: |
| 0.90 미만 | 117 | 33/53 | 438 | 20 |
| 0.95 미만 | 185 | 43/53 | 370 | 10 |
| 0.99 미만 | 302 | 49/53 | 253 | 4 |

0.95 기준에서는 33.3%의 입력을 검토해 오답의 81.1%를 포착합니다. 이번 평가셋에서 사후 계산한 결과이며 운영 임계값을 검증한 결과는 아닙니다. 출력이 긴 경우 최소값이 낮아질 기회도 많으므로 작업 수와 출력 길이를 함께 고려해야 합니다.

## 05의 보존 예측과 비교

[05 evaluation.json](../../05_weighted_concat_refined/results/evaluation.json)의 현장 규칙 JSON을 파싱하고 보드판 원문 및 정답을 내용으로 대응했습니다. 프롬프트 문구와 JSON 공백은 다르지만 이 세 요소의 조합은 중복 건수까지 포함해 555건 모두 같습니다. 550개 고유 조합 중 545개는 유일 대응이고, 5개 조합은 각각 두 번 존재합니다. 중복 10건은 두 실험 모두 정답이므로 개별 대응의 모호성이 개선 및 퇴행 건수에 영향을 주지 않습니다. 케이스 번호나 배열 위치만으로 대응하지 않았습니다.

| 항목 | 05 | 07 | 차이 |
| --- | ---: | ---: | ---: |

| 전체 일치율 | 85.77% | 90.45% | +4.68%p |
| 오답 | 79 | 53 | 26건 감소, 상대 32.9% 감소 |
| 정답 작업 1개 | 189/213, 88.73% | 204/213, 95.77% | +15건 |
| 정답 작업 2개 이상 | 287/342, 83.92% | 298/342, 87.13% | +11건 |

| 저장된 채점의 변화 | 건수 |
| --- | ---: |
| 모두 정답 | 467 |
| 05 오답, 07 정답 | 35 |
| 05 정답, 07 오답 | 9 |

05의 원문 예측도 07의 엄격한 기준으로 일회성 재계산했으며 JSON 스키마 위반은 없고 476건의 기존 정답 판정과 모두 일치했습니다. 이는 저장된 예측의 채점 확인이며 모델 재평가나 05의 당시 코드 복원이 아닙니다.

개선된 35건 중 24건은 05에서 공종과 규격의 다중집합은 맞고 수량만 달랐던 사례입니다. DG3 / 29의 입상 수량 환산, GJ / 558의 단면 PVC 환산, SB의 실리콘마감 합계에서 개선됐습니다. SB의 유사 패턴이 반복되므로 35건이 서로 다른 35개 패턴의 해결을 의미하지 않습니다. 규격 없는 마감 공종에서 05가 넣던 규격을 07이 빈 문자열로 출력한 개선도 있습니다.

퇴행은 SB / 617의 수량 17을 1로 축소, GJ / 290 및 SB / 636의 수량 절반 출력, JW / 63의 에어컨 50*5를 덕트 규격으로 해석, DG4 / 49와 JW / 85의 마감 누락 등입니다. 총수량이 같은 객체 합산으로 오답이 된 GJ / 509도 포함합니다.

05는 test_type과 식별자가 없고 당시 test.jsonl, 분할 메타데이터, 학습 코드와 가중치가 없습니다. 07의 유형을 옮겨 05의 seen 및 unseen 성능을 추정하지 않습니다. 평가 내용은 같지만 학습 분할의 동일성은 검증할 수 없으며 05의 최대 입력 1,024토큰 설정에 대한 실제 잘림 여부도 확인되지 않습니다. 모델 계열과 크기, 프롬프트, 가중 증강, 정밀도와 실행 환경이 함께 달라졌으므로 향상 전체를 모델 크기나 가중치 제거 하나의 효과로 해석할 수 없습니다. 06은 원본 결과가 삭제되어 같은 방식으로 대응할 수 없습니다. 모델별 토큰 신뢰도의 수치 차이도 정확도 차이로 해석하지 않습니다.

## 입력과 정답의 검토가 필요한 사례

다음 식별자는 07 기록 기준이며, 05는 규칙, 원문과 정답 내용으로 유일 대응했습니다. 다섯 건 모두 두 실험의 보존 채점에서 오답입니다. 정답은 두 기록에서 동일합니다.

| 07 식별자 | 05 case_id | 입력과 정답의 차이 | 05의 예측 | 07의 예측 |
| --- | ---: | --- | --- | --- |
| DG2 / 200 | 98 | 입력 2100*100, 정답 2100*1000 | 무보온덕트와 마감 모두 2100*100 | 05와 전체 예측 동일 |
| HG / 5 | 363 | 입력 오픈 100*200, 정답 1000*200 | 오픈 100*200 수량 1, 덕트 수량 2 | 오픈 100*200 수량 0.5, 덕트 수량 1로 수량은 정답과 일치 |
| GJ / 385 | 255 | 입력 무덕트, 정답 보온 계열 | 무보온덕트와 무보온 마감 | 05와 전체 예측 동일 |
| GJ / 17 | 165 | 입력에 오픈구가 있으나 정답에는 없음 | 오픈 1400*600 수량 0.5, 600*600 수량 1.5, 금속관 350 수량 2 | 오픈 두 규격은 유지하되 600*600 수량 1, 금속관 350 수량 1 |
| GJ / 19 | 166 | 입력에 오픈구가 있으나 정답에는 없음 | 오픈 1400*600 수량 0.5를 추가 | 05와 전체 예측 동일 |

서로 다른 모델이 같은 방향으로 해석했다는 점은 정답 검토의 근거지만 정답 오류의 확정 근거는 아닙니다. 원본 사진이나 정정 이력을 확인해야 합니다. GJ / 3처럼 입력은 무덕트인데 정답은 보온 계열인 사례에서 07만 정답으로 채점된 경우도 있으므로 점수 상승 전체를 의미 해석 향상으로 볼 수 없습니다. 정답, 입력, 원본 평가 점수는 변경하지 않았습니다.

## 후속 확인 방향

우선 위 사례의 원본 근거와 동일 공종 및 규격의 합산 또는 중복 보존 기준을 확인해야 합니다. 그다음 단면과 양면의 적용 범위, 반복 수량과 마감 횟수, 뒤따르는 작업의 위치 계승 사례를 보강하고 별도 데이터로 평가하는 것이 적절합니다. 현장별 공종 및 규격 검증과 최소 신뢰도는 사람 검토 우선순위에 활용할 수 있으나 자동 정답 보장 수단은 아닙니다. 이 문서는 후속 방향을 기록하며 해당 변경이나 새 실험을 수행한 결과는 아닙니다.
