## 전체와 유형별 결과

네 시드의 정답 수 차이 합계는 +36건입니다. 복합 홀드아웃에서 +28건, 희소 패턴에서 +11건, 학습에 등장한 패턴에서 −3건이었습니다. 순증가 36건 중 25건이 시드 46에서 나왔습니다. 시드 반복마다 같은 555건을 사용했으므로 이 합계는 반복 평가에서의 정답 수 차이입니다.

## 기록 검증

8개 평가 보고서의 각 케이스를 `(site, image_id, source_index)`, 입력, 정답으로 [test.jsonl](../data/test.jsonl)에 대응했습니다. 유형은 해당 파일과 [split_meta.json](../data/split_meta.json)의 인덱스가 일치하는지 확인했습니다. 유형별 건수와 정답 수의 합은 조건별 전체와 일치하고, 당시 평가 정답과 현재 테스트 정답은 동일합니다.

평가 보고서에 기록된 입력, 학습 설정과 어댑터 파일의 해시 및 학습 설정의 입력과 학습 이력 해시는 보존 파일과 일치했습니다. 평가 코드의 구현 해시는 일치했고 학습 구현 해시는 현재 보존 코드에서 계산한 값과 달랐습니다.
