## 평가 요약

| 유형 | 평가 건수 | 정답 수 | 일치율 | 값 토큰 최소 신뢰도 (0~1) |
| --- | ---: | ---: | ---: | ---: |
| 전체 | 555 | 476 | 85.77% | 0.4350 |

최소 신뢰도는 해당 행의 정답·오답 케이스에 기록된 value_min_confidence의 최솟값입니다. workType·spec·quantity의 값 구간에 해당하는 토큰을 대상으로 하며, 전체 JSON 토큰의 최소 신뢰도나 케이스별 최소 신뢰도의 평균과 구분합니다. 저장된 소수 4자리 값을 그대로 집계했습니다.

**유형별 집계 미확인:** 평가 JSON에 test_type이 없고 당시 test.jsonl·분할 메타데이터도 없습니다. 전체 결과와 값 토큰 최소 신뢰도만 표기하며 다른 실험의 분할로 유형을 추정하지 않았습니다.

예측·정답·점수·설정과 기존 경로 문자열은 원문 그대로 보존합니다.
run_config.json은 min_weight=0.01의 실제 실행 기록이며 evaluation.json은 555건 평가 결과입니다. 경로만 존재하는 누락 자료는 복원하지 않았습니다.
