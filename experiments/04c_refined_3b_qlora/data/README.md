# 데이터 준비 자료

- [refined_global_meta.json](refined_global_meta.json): 기존 전역 정제 분할 메타데이터 원문
- [split_meta.json](split_meta.json): 기존 분할 인덱스·요약 원문
- [test.jsonl](test.jsonl): 보존된 평가 메시지
- [train.jsonl](train.jsonl): 보존된 학습 메시지, 실시간 증강 전
- [work_type.json](work_type.json): 이관 시점 공통 마스터의 독립 사본; 생성 코드는 없음
