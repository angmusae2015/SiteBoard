# 정제 데이터 · 3B QLoRA 설정

이전 정제 데이터 실험에서 분리한 QLoRA 설정입니다. 실행 여부는 확인되지 않았습니다.

- 상태: 설정만 보존
- 기본 모델: Qwen2.5-3B-Instruct
- 데이터: 기존 정제 분할의 준비 자료 사본: 학습 1,568건 / 평가 555건.
- 완전 일치율: 실행 미확인

## 자료 위치

- [데이터](data/README.md)
- 기존 설정: [config_qlora.json](config_qlora.json)

## 재현 범위

정확한 당시 실행 코드가 확인되지 않아 과거 노트북 구성은 보류했습니다. 당시 분할·예측·정답·점수와 보유 모델을 보존하며 공통 최신 정제본으로 교체하지 않습니다.

data/work_type.json은 이관 시점 공통 마스터의 사본입니다. 생성 스크립트는 없으며 당시 실행과 동일 파일인지는 미검증입니다. 과거 JSON의 경로는 원문 기록이며 현재 실행용 경로로 사용하지 않습니다.

기존 config JSON은 이전 구조 정리에서 구성한 설정으로, 당시 실행값 전체를 복원한 것으로 검증되지 않았습니다.

data/는 이전 정제 실험의 준비 자료 사본입니다. 이 조건으로 학습·평가했다는 증거가 아니며 학습 결과와 가중치는 없습니다.
