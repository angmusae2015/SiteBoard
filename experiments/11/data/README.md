# 실험 11 입력 데이터

| 파일 | 역할 |
| --- | --- |
| `42_train.json` ~ `46_train.json` | 시드별 검색 예시 1,712건 |
| `42_test.json` ~ `46_test.json` | 시드별 평가 입력과 정답 428건 |
| `dataset.json` | 분할의 중복, 누락, 레코드 변경을 검증하는 실험 11 원본 2,140건 |
| `work_type.json` | 현장별 공종 및 규격 마스터 |

실행에는 보존된 분할 파일을 그대로 사용합니다. 배치 준비 단계에서 각 시드의 train과 test를 `(site, image_id)` 기준으로 원본과 전수 대조합니다. 마스터도 전수 대조하며 고정 규격의 정수는 문자열로 비교합니다. 빈 목록은 빈 규격, `null`은 `가로*세로` 형식의 가변 규격을 뜻합니다.
