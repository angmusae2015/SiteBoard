### GPT TF-IDF Cosine에서 높은 N이 개선한 사례

DG3 #51의 원문은 `1번 벽체 무 1100*1100 차열마감1번 보 50*3 단면`입니다. Top_K를 5, 10, 20, 30으로 각각 고정했을 때 N=2는 모두 오답이고 N=3, 4, 5는 모두 정답이었습니다. [테스트 원문과 정답](../data/42_test.json) · [GPT 케이스별 결과](seed42-02/evaluation.cases.jsonl)

Top_K=30에서 정답과 네 응답의 첫 두 항목은 모두 `무보온덕트벽체 1100*1100 수량 0.5`, `무보온벽체차열재마감 1100*1100 수량 0.5`입니다. 마지막 `보 50*3 단면`의 해석에서 차이가 났습니다.

| N | GPT의 마지막 항목 | 완전 일치 | N=2와 겹친 예시 | 핵심 예시 순위 |
| ---: | --- | --- | ---: | --- |
| 2 | 보온덕트벽체, 규격 `50*3`, 수량 0.5 | 오답 | 30/30 | 상위 30개에 없음 |
| 3 | 금속관벽체, 규격 `50`, 수량 1.5 | 정답 | 24/30 | 1위 |
| 4 | 금속관벽체, 규격 `50`, 수량 1.5 | 정답 | 22/30 | 1위 |
| 5 | 금속관벽체, 규격 `50`, 수량 1.5 | 정답 | 23/30 | 1위 |

핵심 예시는 `6번 벽체 무 600*400 차열마감1번 보 50*3 양면`입니다. 첨부된 정답은 마지막 부분을 금속관벽체, 규격 `50`, 수량 3으로 처리합니다. N=4의 8위와 N=5의 3위에는 `보 50*2 단면`을 금속관벽체, 규격 `50`, 수량 1로 처리한 예시도 있었습니다. N=3~5의 상위 5개는 각각 N=2의 상위 5개와 겹치지 않았습니다. 높은 N에서 금속관 해석을 직접 보여주는 예시가 상위에 들어간 점은 응답 개선의 가능한 설명입니다. 해당 예시 하나의 효과를 확인하려면 다른 예시와 순서를 고정하고 그 예시의 포함 여부를 비교해야 합니다.

## 결과 파일

실행 ID마다 `manifest.json`에 모델, 검색 조건, 입력 해시와 예상 요청 수를 기록합니다. `state.json`에는 원격 배치 ID와 응답 파일의 위치를 기록합니다. 요청과 응답은 JSONL로 보존합니다.

GPT 실행은 별도 실행 ID를 사용합니다. OpenAI에서 내려받은 출력과 오류 JSONL은 `custom_id`로 평가 대상과 연결합니다.

평가 스크립트는 요청 키별 결과를 `evaluation.cases.jsonl`에, 시드와 검색 조건별 집계를 `evaluation.summary.json`에 저장합니다. 완전 일치는 작업 배열의 순서를 무시하고 `workType`, `spec`, `quantity`가 같은 항목의 개수까지 비교합니다. 모델 출력의 JSON 형식 오류는 오답으로 집계합니다. API 오류나 응답 누락으로 평가할 수 없는 건은 미평가로 기록하고, 정확도 분모는 평가 건수로 표시합니다.

토큰 사용량은 입력, 출력, thinking 토큰을 포함하는 API의 `usageMetadata.totalTokenCount`로 집계합니다. 사용량이 기록된 응답의 합계와 건당 평균을 보고하며 누락 건수를 함께 기록합니다. 값 토큰 최소 신뢰도는 미기록입니다. 분할에는 평가 유형 라벨이 없어 전체와 시드별 집계를 제공합니다.
